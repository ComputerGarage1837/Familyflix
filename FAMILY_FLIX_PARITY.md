# Family Flix Windows parity tracker

This is the release gate for the Windows client. A successful build alone does
not mean it can replace the Android TV app. Each row needs a Windows interaction
check against the same Jellyfin server and user profiles before release.

| Area | Windows source today | Required check or work |
| --- | --- | --- |
| Fixed server URL and visible-user sign in | Native API client and visible-user sign-in screen coded | Verify passwordless/password accounts, profile switch and persisted sign-in |
| Native playback, audio and subtitle tracks, resume | Native libmpv launch, audio/subtitle track chooser, resume and session reporting coded; rapid next-item transitions now queue playback reports until the prior item is stopped | Test representative x265 movies, older TV audio, subtitles, resume, seek, playlist hand-offs and watched-status sync; build full controls |
| Up Next after an episode | Native next-unwatched-episode lookup and Extended/Minimal/Off end screen coded | Test season boundaries, multi-episode files, Kids Mode and remote focus; per-series autoplay choices and automatic-next behavior are not yet ported |
| Home libraries, preferred order, hidden libraries, Continue Watching and Deck | Native Qt home loads libraries and rows; All Libraries browses paginated collections; per-user library order, rail visibility, item-identity focus restoration across live row changes and active-older-season Deck correction are coded | Verify ordering/visibility persistence, full-library browsing and Deck against watched older seasons on real profiles |
| Personal and family Watchlists | Native personal and family Watchlist read, display, membership and voting coded | Test cross-device sync, revision conflicts and playback auto-removal |
| Mixed movie/show/episode playlists | Native server-backed list, create, create-and-add, rename, paginated browse, add, remove, reorder, Play all and Play from here controls coded; sequential playback and series-to-episode expansion coded | Test large playlists, mixed playback order, automatic next item, rename, and create-and-add flow on real server |
| Profile switch and Watch Together | Native visible-user chooser, saved-profile switching, participant selection, combined label, feed owner, playback reporting, server-synced presets, exit flow and fair merged group Deck coded | Test login/profile switching, presets, party reporting and Deck against multiple real profiles; add Android active-older-season correction per group participant |
| Family Night and household voting | Native picker merges current/Watch Together personal Watchlists, resolves moved items by title and provider ID, filters type/runtime/age/genre, rerolls, opens details or plays a movie/first unwatched show episode; playback resolves current viewer's state first; household voting is available on item details | Test with real multi-profile lists, moved items, ratings, episode lookup and vote sync |
| Kids Mode | Per-profile local settings for enablement, spoiler hiding, bedtime, episode limit and parent PIN coded; profile access requires PIN when Kids Mode is on; playback checks bedtime; session sleep timer and playlist episode-limit guard coded | Verify PIN/profile switching, hidden art/text, bedtime, playlist episode limit and sleep timer on Windows; extend episode-limit guard to all automatic-next routes |
| Backdrops, themes and detail actions | Native details and artwork selection following Android's wide-background priority (item backdrop, parent backdrop, wide thumbnails, then wide primary), focus-driven backgrounds and 60-second random idle rotation, show/season/episode navigation and cast, watched/unwatched action, compact single-row actions and 15 palette choices coded | Verify artwork against real media, then port remaining Android detail actions and settings without inventing independent preferences; test remote focus and theme contrast |
| Intro, recap, preview and outro prompts | Native segment fetch, Ask/Auto/Off defaults and playback prompt coded | Build and runtime test detection, timing, focus and per-series choices |
| Live TV guide, preview, categories and time shifting | Native categories, channel list, two-hour viewport/scrolling timeline, preview/fullscreen selection coded | Test live playback, guide timing, category/disabled-channel handling, pause/seek and buffer controls |
| Movie/show and Live TV one-hour buffers | Native libmpv buffer logic and separate 5–60 minute settings are wired to a Windows settings screen with free-storage display; memory-first then capped temporary-disk fallback is coded | Test long VOD and live playback, storage cap, buffer cleanup and seek behavior; actual hour depends on bitrate and stream seekability |
| Issues and broken-media warnings | Native item-detail warnings and movie/episode reporting coded against the server plugin | Test reports and warnings; admin Health Centre remains in the Jellyfin dashboard as requested |
| Settings sync and updates | Native session/theme/other local preferences persist through installs; Watch Together presets sync through Jellyfin; native Windows release check prompts only for a newer release containing a Windows installer | Installer currently opens as a download rather than installing automatically; complete Android-like settings screens and verify update prompt/persistence with the first Windows release |
| Keyboard, mouse and remote | First native Qt controls and hidden-until-interaction playback bar coded | Test D-pad, Back, page restoration and focus on every screen |

The Windows installer should be published only after all checks pass. Until
then the Android TV release remains the complete Family Flix client.
